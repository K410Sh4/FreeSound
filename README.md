# FreeSound / LivreSom Android

Aplicativo Android para pesquisa, reprodução e download de músicas com licenças permissivas.

O código-fonte nativo e o fluxo de build automático serão mantidos neste repositório. APKs ficam em GitHub Actions (artefatos de build) e em Releases (versões).

O aplicativo não oferece extração de conteúdo protegido de Spotify, YouTube ou outros serviços.
